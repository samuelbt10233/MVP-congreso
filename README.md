# MVP Congreso ETITC

Sistema de gestión logística del Quinto Congreso de Ingeniería, Desarrollo Humano y Sostenibilidad Global (15–16 oct. 2026). Versión de demostración.

## Requisitos

Node.js 20 o superior.

## Uso

```bash
npm install
npm run reset   # recrea la base con datos de demo
npm run dev     # API en :3000 y web en :5173
```
